# 星座名片

> 根据“U16190...的星座...”页面截图整理。
>
> 来源图片：`15c7d9edeb3b01b06588e6fd596e6099.jpg`
>
> 标记说明：`截图可确认`为页面直接呈现的功能；`待确认`为完整名片分享流程可能需要，但截图未直接展示的功能。

## 页面定位

将用户的星座和星盘配置组合为可展示、可分享的个人星座名片，帮助他人快速了解用户的性格特点和联系方式。

## 截图可确认功能

- 返回上一页
- 小程序更多菜单
- 用户昵称或 ID 与星座标题
- 太阳、月亮、上升星座卡片
- 火星、金星、水星等星体配置卡片
- 北交点、婚神星等补充配置卡片
- 每张配置卡片显示星座名称和人格标签
- 星座特点文字解读
- 联系方式区域及无联系方式提示
- 与好友交换名片

## 待确认功能

- 从星座解读页生成名片
- 编辑名片公开信息与联系方式
- 生成图片、保存到相册、微信分享和链接分享
- 扫码或链接接收好友名片
- 名片隐私设置、撤销分享和过期控制
- 用户星盘资料缺失时的补全流程
